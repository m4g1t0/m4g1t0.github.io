Objetivo

Una IA en casa que trabaje conmigo

Te cuento cada paso para que puedas montar tu IA en casa sin complicaciones.

El problema y la solución

La idea es tener una IA propia sin depender de APIs de pago. Para ello se usa un Mac Studio dedicado solo a esto, con chip M4 Max y 64 GB de memoria. El objetivo es doble: charlar con el modelo local desde el iPhone con buena calidad, y ver desde el iPhone qué trabajos están en marcha, cuáles esperan un visto bueno, qué resultados han salido y cómo van los recursos.

Cómo está montado

El sistema se construye con unas pocas reglas claras. El sistema en marcha no usa ninguna API de pago. La comunicación ocurre exclusivamente a través de una red privada protegida con HTTPS; nada escucha hacia internet abierto. Todo lo que se expone requiere autenticación. Las acciones delicadas, como enviar o borrar correos, publicar, instalar software o abrir puertos, esperan un visto bueno. Cada cambio realizado tiene vuelta atrás y se anota. Una tarea se da por hecha cuando las pruebas pasan y se ve funcionando desde el iPhone.

Para repetirlo en casa

El trabajo avanza por fases, una a la vez, con cambios pequeños. Cada paso queda escrito para que cualquier persona pueda repetirlo. Si quieres montar algo parecido, empieza por ahí: una fase cada vez y un visto bueno para lo delicado.

La idea de fondo

La IA está para hacer el trabajo y dejar lo importante a las personas: elegir el rumbo, el estilo y lo que se queda. Por eso todo lo delicado espera un visto bueno, y por eso esta web es el ejemplo. La han construido IAs, pero la idea y el estilo los ha elegido una persona.
