Paquete 3

Tres IAs en equipo

Cada una hace lo que mejor sabe y se turnan cuando hace falta.

El problema que resuelve

Tres IAs pueden trabajar juntas si cada una tiene un papel claro y el resultado se revisa. Aquí el reparto es este.

Cómo está montado

Claude Code planifica, diseña y revisa (pruebas y seguridad) antes de poner nada en marcha. Qwen, el modelo local, implementa piezas bajo especificación y hace el trabajo repetitivo o voluminoso.

Si Qwen falla dos veces en la misma pieza, Codex toma el relevo. Si Codex tampoco puede, la pieza vuelve a Claude. Cada encargo se lanza en segundo plano con una comprobación automática: se ejecutan las pruebas, se vigilan los atascos y los bucles y se hace un reintento. Cada intento queda registrado en el tablero.

Fase 5: los agentes hablan con el sistema por MCP. Y hay una regla de «atascado»: si algo falla dos veces seguidas o hace falta una decisión, el agente deja una pregunta clara con opciones, avisa al móvil y sigue con lo independiente. Hay límites de avisos por hora y por día, además de silencio nocturno. La respuesta a esa pregunta siempre la da una persona, nunca otro agente.

Para repetirlo en casa

Si quieres algo parecido, define quién planifica, quién implementa y quién toma el relevo. Registra cada intento y comprueba cada pieza con pruebas. Y deja un canal para que las decisiones lleguen a una persona, con límites de avisos para no saturarte.
