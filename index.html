CEO & Herrero
Guía humana Encargo para IA GitHub

Dos Codex. Un mismo taller.

CEO es un Codex con GPT que planifica: escribe la especificación, aclara, diseña y reparte tareas. Herrero es otro Codex con Qwen local que implementa esas mismas tareas sobre los mismos archivos. El usuario cambia de sesión; ellos no se invocan entre sí.

Montarlo paso a paso Pasárselo a mi IA

Cómo se reparte el trabajo

CEO — Codex con GPT
$speckit-specify
$speckit-clarify
$speckit-plan
$speckit-tasks
→ ↓
Herrero — Codex con Qwen local
$speckit-implement

Ambos terminales leen y escriben los mismos artefactos compartidos: spec.md, plan.md y tasks.md en specs/<feature>/, con la feature activa registrada en .specify/feature.json. El traspaso es manual: tú cierras la sesión de CEO y abres la de Herrero en la misma carpeta.

Qué hay dentro del montaje

  • CEO Codex CLI con proveedor OpenAI (GPT) y tu propia cuenta de ChatGPT. Solo planifica: specify → clarify → plan → tasks.
  • Herrero Otro Codex CLI con proveedor local lmstudio, sirviendo un Qwen descargado en LM Studio. Solo implementa: implement.
  • LM Studio es el servidor de inferencia del Qwen (loopback, puerto 1234). No añade otra capa de agentes: solo sirve el modelo.
  • Spec Kit compartido en la carpeta del proyecto: cinco skills (specify, clarify, plan, tasks, implement) y los artefactos de cada feature.
  • Mismo checkout, dos homes: cada Codex tiene su propio CODEX_HOME (config, AGENTS y autenticación separados) pero ambos trabajan con el mismo -C.

El cambio de sesión es manual

No hay orquestador, workflow automático ni invocación cruzada. Cuando CEO termina tasks, tú copias la orden de implementación y abres Herrero en el mismo workspace. Herrero ejecuta las tareas una a una, verifica cada una y la marca en tasks.md. Si algo queda bloqueado, lo comunica; no improvisa.

Referencia del montaje documentado

Esta web describe el montaje observado en un Mac con Apple M4 Max y 64 GiB de memoria unificada el 2026-09-26: Codex CLI 0.156.1, LM Studio 0.4.25+1 y Spec Kit 1.0.11, con un Qwen local de ~22,8 GB (etiqueta Qwen3.8-27B-Uncensored-6bit/6-bit, identificador estable 6-bit). Son valores de referencia, no requisitos universales ni benchmarks: en la guía se separan los parámetros que debes adaptar a tu Mac de lo observado aquí.
