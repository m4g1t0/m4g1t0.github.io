Tablero y panel

Cada trabajo queda apuntado y puedes ver el estado del sistema desde el móvil.

El tablero como fuente de verdad

Cuando varias IAs trabajan solas, conviene poder ver qué han hecho y cuándo. Aquí, cada trabajo deja constancia de su inicio, su fin, su resultado y cualquier error que haya surgido. Hermes actúa como único planificador y gestor de cola. El tablero es la única fuente de verdad para todo esto.

Hay copias restaurables. Además, hay información que Hermes no guarda directamente. Esa parte vive en una base de datos aparte, conectada al tablero mediante el identificador de cada tarea. Esto permite ampliar la información sin tocar ni modificar el esquema original de Hermes.

La puerta y la vista móvil

El camarero es una API local pequeña. Es la única vía para acceder al tablero. Al principio funciona solo en modo lectura. Después, se añaden aprobaciones con una clave distinta que solo vale para aprobar.

El panel es una app web instalada en el iPhone. Tiene pantallas de Actividad, Aprobar (con botones), Biblioteca y Sistema. Solo habla con el camarero. Cuando no puede leer el tablero, se pone en rojo. Si se cae el camarero, Hermes sigue trabajando y solo se pierde la vista desde el móvil.
